# QR Code Generator

A simple and responsive QR Code Generator web application built using HTML, CSS, and JavaScript. It allows users to generate QR codes for any text or URL and download them as PNG images.

🚀 Features
- Generate QR codes from text or URLs
- Select different QR code sizes
- Download generated QR code as PNG
- Responsive and user-friendly interface
- Client-side only (no backend required)

🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- QRCode.js Library

📂 Project Structure
```
QR-Code-Generator/
│── index.html
│── style.css
│── script.js
│── README.md
```

📸 How to Use
1. Open `index.html` in your web browser.
2. Enter any text or URL.
3. Select the desired QR code size.
4. Click **Generate**.
5. Click **Download** to save the QR code as `QR_Code.png`.
